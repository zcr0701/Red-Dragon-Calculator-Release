## 注意事项（来自 Codex 对话）

- GUI 需要 PyQt5 + PaddleOCR，建议在 `paddleocr_env` 环境运行（本机 pip 混装会坏 DLL）。
- beam 搜索能找到即证明存在，但束剪枝不是严格的"不存在"证明；6 龙在束宽 4000/8000 下未搜到。
- 晦鳞巢母真卡为 3费4/3 龙，模型里为 3费3/3 且无龙族标签（效果一致，影响小）。
- PowerShell 中文乱码：先设 `$env:PYTHONIOENCODING='utf-8'`。
