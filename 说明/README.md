# 炉石红龙贼计算器

本项目是以 **Codex 对话**（2026-08-03，Codex 桌面应用会话「理解提供的文件」）中的最终修改版为准的红龙贼（牛转 / 牛舞）计算器项目，用 git 管理版本和分支。

## 运行方式

### 命令行（不需要 GUI 依赖）

```powershell
# 红龙路径计算：给定手牌，反向符号链搜索可达路径
python 代码/red_dragon_calculator.py --hand "狐人老千,斯卡布斯·刀油,鲨鱼之灵,晦鳞巢母" --search

# 束搜索模式（默认关闭，需显式加 --beam）
python 代码/red_dragon_calculator.py --hand "..." --search --beam --beam-width 4000

# 关闭反向搜索时的正向自动挖掘（默认开启；会额外跑一次束搜索兜底）
python 代码/red_dragon_calculator.py --hand "..." --search --no-forward-mine

# 从 OCR 文本重建手牌（支持 --text / --file）
python 代码/rebuild_hand.py --text "手牌中(9)`n0 狐人老千`n4 鲨鱼之灵"

# 计算前自动查重（相同局面直接输出历史路径，不再重算）；计算后自动归档
python 代码/red_dragon_calculator.py --hand "..." --search

# 把局面存档提交并推送到云端（GitHub 仓库）
python 代码/red_dragon_calculator.py --sync-archive
```

主要参数见 `python 代码/red_dragon_calculator.py --help`。

### 图形界面（需要 PyQt5 + PaddleOCR）

```powershell
python 代码/ocr_region_gui.py
```

界面支持框选截图区域、选择牛头人酋长剩余卡池（舞动全场 / 幻觉药水 / 生命缚誓者阿莱克丝塔萨）、查看初始状态摘要；顶部「手动输入」按钮可展开手牌栏 / 战场（随从栏）/ 当前效果三个输入区，复用正则规则解析后直接开始计算；「beam模式」复选框默认不勾选。计算结果会写入 `代码/logs/red_dragon_all_paths_时间戳.txt`。

「自动挖掘」复选框默认勾选：反向符号链搜索到最高目标未证明时，会自动再跑束搜索发现模板外的新线路，并把找到的路径反推成符号链做反向验证（先正向试探、再反向证明）。束宽不足会自动升级（1000→2500→5000）直到摸到搜索下限；追求速度可取消勾选，或用命令行 `--no-forward-mine` 关闭。

## 当前已确认的状态（截至 Codex 对话 2026-08-03）

- 计算器以"反向符号链模板"为主，另带可选的正向 beam 束搜索（默认不勾选）。
- 反向符号链搜索范围已修复：设置「搜索龙数上限 6 / 下限 4」时会依次搜索 6、5、4（此前 bug 导致只搜下限 4，5 龙线路被整体跳过）。
- 反向符号链升级为「双向符号链证明」：前向从初始局面按束展开，反向从目标龙数反推尾链（直出 / 暗影施法者复制 / 暗影步回手 / 舞动回收 / 药水复制 / 牛头人发现 / 骨刺·伺机铺垫），在前沿状态处拼接后经反向验证确认——像证明数学题一样两头向中间凑。
- 模板已拆分为子链库（`build_template_subchain_library()`）：从第一张红龙处把模板切成「起手段 / 尾段」，97 条起手段 + 37 条尾段，供双向引擎在生成前向候选链和反向尾链时直接复用拼接（例：`鱼狐刀暗(刀)牛`、`鱼刀刀龙`、`鱼狐刀牛(舞龙)晦步(刀)刀暗刀` 均可在子链库中找到）。
- 保留「正向束搜索自动挖掘」兜底：双向未命中时才启用，束宽不足会自动升级（1000→2500→5000）。
- 局面存档（`存档/红龙贼-情况存档.json`）：每次搜索结束按「手牌 / 战场 / 状态 / 牌库」归档。去重规则：手牌乱序视为一致（按 名称+费用+类型 排序后比较），费用、卡牌类型、数量不一致视为不同局面。路径保留规则：N<4 龙只保留一条路径，N≥4 龙全部保留。每次计算前先查档，命中直接输出，不重复计算；`--sync-archive` 把存档 push 到 GitHub 云端，实现多端共享。
- 搜索算法调研见 `说明/搜索算法调研.md`（Pikafish/Stockfish、五子棋威胁空间、斗地主 MCTS 等的剪枝设计，及对本项目的借鉴对照）。
- 已确认：基础 2/3/4 龙路径；狐人老千[0费] 场景下 5 龙成立（`公式预启动鲨鱼舞动重铺五龙链`，5 龙 / 72 伤害 / 剩 2 法力 / 0 爆牌）；战场已有鲨鱼之灵的预启动 4 龙路径仍成立（4 龙 / 64 伤害 / 剩 4 法力）。
- 舞动全场回手已改为真炉石规则（按进场顺序回手，手牌满时后进场先爆）。
- 未确认：6 龙及以上未证明（beam 束宽 4000/8000 均未搜到；束搜索只能证明存在，不能严格证明不存在）。

## Git 分支约定

- `main`：稳定里程碑，只合并验证过的版本。
- `dev`：日常修改都在这个分支上，改完想留档时再提交，不必每次修改都提交。
