1新增：内存读卡组自动识别

无需再手动输入卡组代码或预设——进入对局，程序自动从炉石进程内存读取当前账号全部卡组，并精确锁定你正在玩的那副。

① 读取原理（HDT/HearthMirror 同款）

  • 向 Hearthstone.exe 注入原生组件，调用 Mono 运行时反射读取 CollectionManager 单例；
  • 遍历 m_decks → valueSlots / touchedSlots 拿到全部卡组（卡组名、英雄卡、按张数展开的卡牌列表）；
  • v1.6.1 由 inject.exe + mem_deck_probe.dll（合计约 0.18MB）接管，替代体积达 126MB 的 frida。

② 命中当前卡组

  • 某英雄只有一副卡组 → 直接命中；
  • 多副同英雄卡组（如 10 副盗贼）→ 用「揭示卡全部在卡组内 + 唯一幸存者」严格区分，绝不静默猜错；
  • 仅公共牌 / 证据不足时不猜，等更多揭示。

实测：连续多次读取运行中炉石的 12 套真实卡组全部成功，含「暗六随红龙贼」「五随红龙贼」「腾六随红龙贼」「龟龟爆牌」「四随苔丝贼」等。

2新增：卡组自动套用预设

命中卡组后，自动推断其中含有的组合随从（鱼 / 狐 / 刀 / 暗 / 牛 / 晦 / 腾…），直接勾选「牌库剩余随从」。

  • 以卡组 CardID 列表为准，命中的组合随从按配置顺序自动勾选，替代手动下拉；
  • 防重写保护：自动套用仅对局首次命中时做一次，之后手动改预设不会被自动覆盖；
  • UI 显示「<自动·暗六随红龙贼>」提示当前来源是卡组自动识别。

4v1.6.1：内存读取改原生实现（体积减半）

在功能不变的前提下，把内存读取载体从 frida 换成原生注入组件，安装包体积显著下降。

体积对比

  • v1.6.0 含 frida（_frida.pyd 约 126MB）：安装包约 95MB；
  • v1.6.1 纯原生（inject.exe + mem_deck_probe.dll 约 0.18MB）：安装包约 43MB，体积减半；
  • 读取链路 / 数据结构 / 返回接口与 frida 版完全一致，功能零损失。

稳定性修复

  • 修复重复注入同一 DLL 路径不触发 DllMain、二次读取超时的问题：每次读取前把 DLL 复制到唯一临时路径再注入，保证每次都是新模块加载；
  • 注入 + 读取放后台线程并限时，游戏卡顿 / 被杀软拦截时 GUI 不被拖住，失败静默回退日志渐进揭示。
