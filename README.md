# 红龙贼计算器 Red-Dragon-Calculator

炉石传说「红龙贼」OTK 计算器 V1.2（单文件版，免安装，双击即用）。

## 功能
- 纯束宽搜索，默认 3 秒内出结果，覆盖 95% 以上最优解
- 实时读取炉石本地 Power.log，自动追踪场面 / 手牌 / 牛内随从 / 殒命暗影
- 小窗分轮显示最高伤害路径（缩写 + 颜色方块）
- 场面交换自动搜索最优解
- 独立的「如果机制」：省费打出抽随从卡后，推演抽到预写组合缺失随从的最高伤害（毫秒级，默认开启）

## 更新日志

### V1.2（2026-08-10）
- **新增独立的「如果机制」（默认勾选）**：计算完成后额外推演——若用手牌中的抽随从卡
  （默认先伺机待发省费打出）抽到预写组合缺失的随从，能达到的最高伤害；
  结果区显示「如果使用 / 可能抽到 / 减费状态 / 随从齐全度 / 预计伤害」。
- **递归抽随从链（深度 ≤10）**：按优先级抽缺失随从（鱼>刀>牛>暗>晦>狐），
  抽到的刀油立即打出成为新的减费状态，让后续抽随从卡连续低成本打出。
- **刀油减费状态模型修正**：一层刀油状态 = 下两张牌各减 2 费（一层 2 槽）；
  鲨鱼之灵在场战吼双触发 = 两层（下两张牌各自 -4）；每打出一张随从消耗每层 1 槽，
  两张随从后状态耗尽；法术抽卡享受减费但不耗槽；暗(刀)复制 1/1 刀油进手牌（不补层）；
  丢晦回 4 法力（鱼在场翻倍）。
- **剪枝条件**：当前状态无任何减费状态（层用尽、伺机/狐已消耗、无刀油可补层）
  即停止递归直接评分，不再按原价展开后续可能性。
- **打分规则**：随从齐全度 > 法力 > 水晶；输出随从齐全度
  （两个预写组合并集 7 个随从已凑齐数）/ 法力 / 水晶 / 预计伤害。
- **性能零影响**：如果机制为独立纯 Python 毫秒级预评估（实测最坏 0.08ms），
  不改启发函数与主搜索，对计算时间无影响。
- 红龙小窗可见标签补充作者标记（CreATedBy此人乃天下绝响#5854）。

## 使用说明
1. 启动后自动解析炉石本地 Power.log，实时读取场面数据
2. 主窗口点击「开始计算」，或点击「小窗」按钮后在小窗点「计算」
3. 束宽默认填 0 即可；怀疑非最优时可不限时 + 大束宽复核
