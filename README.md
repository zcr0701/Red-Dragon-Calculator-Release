# 红龙贼计算器 Red-Dragon-Calculator

炉石传说「红龙贼」OTK 计算器 V1.3.1（单文件版，免安装，双击即用）。

## 功能
- 纯束宽搜索，默认 3 秒内出结果，覆盖 95% 以上最优解
- 实时读取炉石本地 Power.log，自动追踪场面 / 手牌 / 牛内随从 / 殒命暗影
- 小窗分轮显示最高伤害路径（缩写 + 颜色方块）
- **WhatIF 分支树**：正常计算后自动展开，独立小窗贴在小窗正下方显示指引树（一条主干+分叉点）；持枪要挟/垂钓时光/潜伏帷幕等分支完整展开，分支严格从主干续算，可点选分支、返回上级/回到主干
- **场面交换算法**：根据海量对局数据反馈设计，覆盖 95% 的预启动复杂情况下的场面交换处理；本回合刚下的随从不参与交换（召唤失调）；实时读取武器攻击/耐久
- **持枪要挟完整分支**：7 个发现结果全部展开（补水/脱水/误炸/袋底藏沙/不许乱动 + 其他快枪牌·随从/法术加权）
- **垂钓时光探底追踪**：自动追踪探底牌，未知底牌按未知杂牌处理
- **观战手牌解析**：支持观战模式解析双方手牌
- **引擎性能优化**：通过多线程(4->16)束搜索（多宽束通道并行 + 通道内多线程）、候选桶预分配、字符串驻留与状态哈希去重、全局 Top-K + 龙数桶保底；实测节点展开速度从 20w/s->50w/s，提升125%
- **精确截断模式**：设置了超过敌人血量斩杀的血量直接截断，速度能提升50%~100%
- 自定义日志路径：手动选择炉石安装目录或 Power.log 文件，解决自动搜不到日志的问题

### V1.2.1（2026-08-10）
- **新增「自定义路径」功能**：状态栏点击「自定义路径」，解决自动搜不到 Power.log 的问题。
  - **选择游戏目录…**：选择炉石安装目录，即**包含 Logs 文件夹的那个文件夹**
    （例如 `D:\Games\Hearthstone`，其下应有 `Logs` 子目录）。
  - **选择 Power.log 文件…**：直接选择日志文件。Power.log 位于炉石安装目录的
    `Logs` 文件夹内（新版为会话子目录），完整路径形如
    `D:\Games\Hearthstone\Logs\Hearthstone_2026_08_10_21_46_40\Power.log`。
  - 选择会被记住，重启后仍生效；「恢复自动检测」可随时取消自定义。
  - 选错路径时（找不到 Power.log）会弹窗提示排查方向（是否含 Logs、是否开启 [Power] 日志）。

### V1.2（2026-08-10）
- **新增独立的「如果机制」（默认勾选）**：计算完成后额外推演——若用手牌中的抽随从卡
  （默认先伺机待发省费打出）抽到预写组合缺失的随从，能达到的最高伤害；
  结果区显示「如果使用 / 可能抽到 / 减费状态 / 随从齐全度 / 预计伤害」。
- **递归抽随从链（深度 ≤10）**：按优先级抽缺失随从（鱼>刀>牛>暗>晦>狐），
  抽到的刀油立即打出成为新的减费状态，让后续抽随从卡连续低成本打出。
- **刀油减费状态模型修正**：一层刀油状态 = 下两张牌各减 2 费（一层 2 槽）；
  鲨鱼之灵在场战吼双触发 = 两层（下两张牌各自 -4）；每打出一张随从消耗每层 1 槽，
  两张随从后状态耗尽；法术抽卡享受减费但不耗槽；暗(刀)复制 1/1 刀油进手牌（不补层）；
  丢晦回 4 法力（鱼在场翻倍）。
- **剪枝条件**：当前状态无任何减费状态（层用尽、伺机/狐已消耗、无刀油可补层）
  即停止递归直接评分，不再按原价展开后续可能性。
- **打分规则**：随从齐全度 > 法力 > 水晶；输出随从齐全度
  （两个预写组合并集 7 个随从已凑齐数）/ 法力 / 水晶 / 预计伤害。
- **性能零影响**：如果机制为独立纯 Python 毫秒级预评估（实测最坏 0.08ms），
  不改启发函数与主搜索，对计算时间无影响。

## 使用说明
1. 启动后自动解析炉石本地 Power.log，实时读取场面数据
2. 主窗口点击「开始计算」，或点击「小窗」按钮后在小窗点「计算」
3. 束宽默认填 0 即可；怀疑非最优时可不限时 + 大束宽复核
