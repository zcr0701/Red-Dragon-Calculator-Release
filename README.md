# 红龙贼计算器 Red-Dragon-Calculator

炉石传说「红龙贼」OTK 计算器 V1.5（单文件版，免安装，双击即用）。

## 功能
- 纯束宽搜索，默认 3 秒内出结果，覆盖 95% 以上最优解
- **四路正交差异化打分**：由「多路重复堆宽」升级为四路正交通道
  （H6 共识 + H14 操作空间 + H12 回收放大 + H16 突破潜力），在覆盖不变的前提下更快更准
- 实时读取炉石本地 Power.log，自动追踪场面 / 手牌 / 牛内随从 / 殒命暗影
- 小窗分轮显示最高伤害路径（缩写 + 颜色方块）
- **WhatIF 分支树**：正常计算后自动展开，独立小窗贴在小窗正下方显示指引树（一条主干+分叉点）；持枪要挟/垂钓时光/潜伏帷幕等分支完整展开，分支严格从主干续算，可点选分支、返回上级/回到主干
- **场面交换算法**：根据海量对局数据反馈设计，覆盖 95% 的预启动复杂情况下的场面交换处理；本回合刚下的随从不参与交换（召唤失调）；实时读取武器攻击/耐久
- **持枪要挟完整分支**：7 个发现结果全部展开（补水/脱水/误炸/袋底藏沙/不许乱动 + 其他快枪牌·随从/法术加权）
- **垂钓时光探底追踪**：自动追踪探底牌，未知底牌按未知杂牌处理
- **观战手牌解析**：支持观战模式解析双方手牌
- **新卡建模**：绿龙「伊瑟拉，翡翠守护巨龙」（战吼 +3 法力、开局双方水晶上限 +5）、锋鳞（费用不低于 2 光环）、疾速矿锄（武器附加伤害）
- **随从组合与牌库跟踪**：可配置组合随从池、抽随从分支池、「牌库剩余随从」勾选、牛池默认三张、确定性折入主线；牛池预设新增 {幻舞龙}/{转舞龙}/{幻转龙}
- **引擎性能优化**：多线程(4->16)束搜索（多宽束通道并行 + 通道内多线程）、候选桶预分配、字符串驻留与状态哈希去重、全局 Top-K + 龙数桶保底、离散路径评分增量跟踪、分支叶持久进程池
- **精确截断模式**：设置了超过敌人血量斩杀的血量直接截断，速度能提升50%~100%
- 自定义日志路径：手动选择 Hearthstone 游戏文件夹（自动追踪其 Logs 下最新会话的 Power.log）或直接指定 Power.log 文件（只记忆游戏目录，炉石重启后自动切换到新会话），解决自动搜不到日志的问题
- **自动开启 Power 日志**：启动时自动确保 log.config 的 [Power] 详细日志开启（LogLevel=1 / FilePrinting=true / Verbose=true），缺则补、错则改、文件缺失自动创建，无需手动配置
- **回合开始自动计算**：轮到你行动自动触发无分支计算；设置面板可开关并记忆
- **预启动模式**：本回合不足斩杀时自动给出「攒手牌」建议（预启动打分 + 腾格格子模型），并以腾格/赌解不掉双场景真实续算下回合龙伤害
- **下回合抽牌预计算**：对手回合后台按牌库权重预演下回合抽到各牌后的伤害并缓存，抽中即秒出

- **回合开始自动计算**：is_my_turn 从 False→True 的边沿自动触发无分支计算；满足条件才触发（开关开启、非手动、无计算运行、对局进行中、回合数≥1）；启动/强刷首次轮询只采样不误触发；文本层捕获玩家名判定当前玩家更稳；设置开关默认开启并可记忆。
- **预启动模式（不足斩杀时攒手牌建议）**：新增引擎 `pre_start=1` 与专用启发 `prestart_score`，与主计算解耦；幻觉药水收尾/舞留手不浪费/暗影步回手续减费/提前下 1 费牛拿舞等成为高价值动作；裸下高价值随从（刀/暗/龙/晦/牛池非空牛）无复制时软惩罚，裸下鱼（狐）是唯一不惩罚裸下。

  - 筛选规则：仅当下回合续算伤害 Z > 本回合无分支伤害时才展示操作序列，否则提示保留手牌待启动——**绝不虚构打不出伤害的路径**。
- **下回合抽牌预计算**：对手回合在后台按牌库权重（组合随从→步/骨/伺/币等特殊牌→其他已知→未知杂牌）逐个预演下回合抽到各牌后的无分支伤害，逐条显示并缓存（墙钟截止+预算兜底）；己方回合抽中直接读缓存秒出，手牌被移出/抽到缓存外/未知费用杂牌无法对齐时自动回退常规计算。

**语义修正与机制贴合实战**
- 行骗/抽牌卡按无分支语义处理：不定向抽牌标注「行骗(法术杂牌+随从杂牌)」，不虚构定向分支；牌库剩余随从池恰 1 张（如只剩牛）时才确定性抽入。
- 抽牌退化：潜伏帷幕（抽2）剩余随从≤2、挖掘/行骗（抽1）剩余随从≤1 时分支标记自动更新，避免虚构。

- 随从行动规则：刚下的随从本回合不可行动，`交换(随从+序号→目标)` 统一好读标注。
